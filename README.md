# NRO Delegated Archive

An archive of historical snapshots of the **NRO Extended Delegated Statistics** dataset, including organization information.

## Data Source

- **Source:** [Potaroo - delegated-nro-extended-org](https://www.potaroo.net/bgp/stats/nro/delegated-nro-extended-org)
- **Dataset:** NRO Extended Delegated Statistics with organization names
- **Resources:** IPv4, IPv6, and Autonomous System Numbers (ASNs)

## Attribution

All data originates from the [Number Resource Organization (NRO)](https://www.nro.net/) and is retrieved from [Potaroo](https://www.potaroo.net/).

This repository is an independent archive and is not affiliated with the NRO or Potaroo.
